# 朝日綠源 ASAHI AGRIA · 機能液肥 857 产品站

「857 号 細胞分裂活性剤（RNA + DNA）」的静态产品介绍站。日式农业技术编辑风：品牌红 `#E31C26` + 深墨绿 + 米白，细线分割、宽字距小标签、绿色斜纹章节标记。

## 结构

```
index.html      单页站点（骨架+内容）
styles.css      全部样式与响应式断点
script.js       导航滚动、入场动画、图片灯箱
assets/         素材：logo / 产品包装 / 核酸贴纸 / 作物图标 / 田间对比图
```

纯静态，无构建步骤，无外部依赖（字体走系统栈，图标为内联 SVG）。

## 本地预览

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

## 部署

GitHub Pages：`main` 分支根目录。

> 素材图片是二进制文件，请通过 git 或网页拖拽上传，**不要**经由 API 接口写入（会被重新编码而损坏）。

## 修改约定

- **版式调整请在 `styles.css` 里改。** 在可视化编辑器里拖拽会把尺寸冻结成内联样式，覆盖响应式规则。
- 图片显示不完整时，先量裁切比例再决定：`object-fit:cover` 的容器比例 ≠ 原图比例就会裁切。
  带贴边标注的图解须按原图比例整张显示（`aspect-ratio:auto; object-fit:contain`）。
- 品牌色只改 CSS 变量 `--red` / `--green`，其余骨架保持统一。
